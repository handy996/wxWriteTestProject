# 代表性验收候选 representative-v1.0.0-rc.1

依赖契约rc.2。独立新版本，不覆盖rc.1工程回归集；200个候选Claim全UNREVIEWED。“代表性”是待产品/人工确认的设计目标，并非已验证质量。

| 类别 | 四篇材料的不同任务 |
|---|---|
| 科学 | 随机试验/退出/区间；横断面混杂；台架实验与饮用安全外推；预印本撤回/同源转载 |
| 历史 | 试航/载客日期；单位换算；署名与劳动者遗漏；航海地图空白与行政名册 |
| 政策 | 生效/截止/豁免；新旧预约过渡；时段/区域；资格/名额/审批结果 |
| 品牌 | 同照度功耗/送样；面料/整包防水；材料/成品认证；单批次容量与更正 |
| 叙事 | 回忆/票据/转述；合照时间线/隐私；传说/量产出处；个体种植观察与因果 |

每类4篇，共20篇；每篇8项来源内可定位命题、1项故意冲突、1项缺证扩展，合计60 CRITICAL、140 MAJOR。正文也可能存在其他应提取事实，标注者必须通读补漏，不能把200条候选当作完整答案。每篇原创primary/reprint/correction三份来源；reprint同源，不能重复计独立证据。

全部研究、地区、品牌、人物、政策和未来日期为虚构测试设定，不是现实专业结论。无外部全文复制；文件hash、使用依据和来源关系在独立index/manifest。类别内仍有共同解释段落用于控制难度，不能声称等同自然真实文章分布；产品可要求获权真实材料另升版本替换。

1. 项目负责人指派两名不同自然人A/B、分歧复核者及产品代表性审核人。assignment.json目前UNASSIGNED，不能由开发agent伪填。
2. 分别交付文章、来源及本人表，盲标人员不看候选建议答案或对方标注；独立通读补漏，保留限定条件、反证和同源关系。
3. 保存原始A/B表，逐条比较并由复核者登记理由/证据/时间。新增Claim或补证形成新版本和映射；≥200个双人主要Claim完成后才能成为ADJUDICATED金标。
4. 产品确认类别与体裁覆盖；不足时取得自有/授权研究解读、历史/政策、品牌和个人叙事材料。权利不明时不保存全文，不冒充已冻结正式集。
5. T08/T09预算与能力就绪后，在同一datasetHash/goldHash真实运行三次。Analyzer独立评分、SRS五维编辑量表、逐篇论点反转检查均必需。

生成器仅首次写入或同字节复现；已有内容/标注变化时拒绝覆盖。人工开始后不得用改过的生成器重写此版本，应新建版本。
